# wasm-rpc

Run a Go Protobuf RPC server inside WebAssembly — in the browser via
`syscall/js` or in any WASI host via a `go:wasmexport` ABI — with
generated clients for **TypeScript, Dart, Kotlin, Swift, and Go**.
Unary and **server-streaming** RPCs. Bytes cross the Wasm boundary
exactly once per direction. Schema workflow is **buf v2**; bindings come
from a first-party plugin, `cmd/protogen-wasm`. Big Go and **TinyGo**
both supported.

```
any client ──serialize──▶ bytes ──one copy──▶ Router.Dispatch / DispatchStream
     ▲                                              │ (goroutine per stream)
 deserialize ◀── frame ◀──one copy── pooled MarshalAppend / MarshalVT
```

## Layout

```
client/
  go/       Transport + StreamTransport ifaces, in-process Loopback
  ts/       runtime (src/) + protoc-gen-es & wasm-rpc gen (gen/)
  dart/     pub package: transports incl. dart:js_interop, gen (lib/gen)
  kotlin/   JVM runtime (coroutines Flow) + java/kotlin gen (gen/)
  swift/    SPM: WasmRpc runtime + WasmRpcGen (swift-protobuf)
cmd/protogen-wasm/   buf/protoc plugin: lang=go|ts|dart|kotlin|swift
examples/
  server-basic/      minimal unary service (echo.v1) + reusable wasm/wasip1 binaries
  server-streaming/  server-streaming service (ticker.v1) + reusable binaries
  web-echo/          Vite+React app with the basic Go server in-page
  web-streaming/     Vite+React app consuming a live Go stream, cancellable
  e2e/               combined test guest, Node e2e, wazero wasip1 host
internal/codegen/    per-language emitters used by protogen-wasm
proto/               buf module (echo.v1, STANDARD-lint-clean)
server/              router, streams, js bridge, wasip1 bridge, errors
buf.yaml  buf.gen.yaml  Makefile
```

## Codegen (buf v2)

`buf generate` produces everything in one pass: `protoc-gen-go` +
`protoc-gen-go-vtproto` (via the go.mod `tool` directive) into `gen/go`,
`protoc-gen-es` into `client/ts/gen`, BSR remote plugins for
dart/java/kotlin/swift, and five `protogen-wasm` passes for the wasm-rpc
bindings.

Per service, the plugin generates:

| Lang | Unary | Server stream |
|---|---|---|
| go | `XServer` iface + `RegisterXServer` + native `XClient` | handler takes `*server.ServerStream[*Resp]`; client `Watch(ctx, req, fn)` |
| ts | `readonly echo = unary(...)` | `readonly watch = serverStream(...)` → `AsyncIterable` + `cancel()` |
| dart | `Future<Resp>` | `Stream<Resp>` |
| kotlin | `suspend fun` | `Flow<Resp>` |
| swift | `async throws` | `AsyncThrowingStream<Resp, Error>` |

Client- and bidi-streaming are skipped with a comment in every backend.

Naming note: the Go suffix is `_wasmrpc.pb.go` deliberately —
`_wasm.pb.go` trips go/build's implicit `GOARCH=wasm` filename
constraint (go/build cuts at the first dot) and silently drops the file
from native builds.

## Streaming contract

Browser global (mounted by `r.Mount("wasmRPC")`):

```ts
invoke(method, payload: Uint8Array): Promise<Uint8Array>
listen(method, payload, {onMessage, onError, onEnd}): number  // stream id
cancel(id: number): void
methods(): string[]
```

One persistent `cancel` export — no per-stream `js.Func` allocations.
Handler panics surface as `{code:"internal"}` with the stack on
`console.error` only. Cancellation ends the stream via `onEnd`, and the
handler observes it as `ctx.Done()` / a `Send` error.

## wasip1 ABI (`go:wasmexport`, Go >= 1.24)

Build a reactor and register from `init()` (reactors run inits, not
`main`) via `server.Attach(r)`:

```sh
GOOS=wasip1 GOARCH=wasm go build -buildmode=c-shared -trimpath -ldflags="-s -w" -o app.wasm ./examples/echo/wasip1
tinygo build -target=wasip1 -buildmode=c-shared -no-debug -o app.wasm ./examples/echo/wasip1
```

| Export | Semantics |
|---|---|
| `wasmrpc_alloc(n) -> ptr` | host allocates an input buffer |
| `wasmrpc_free(ptr)` | release any guest-returned buffer / input |
| `wasmrpc_invoke(mPtr,mLen,pPtr,pLen) -> u64` | packed `ptr<<32\|len` result frame |
| `wasmrpc_stream_open(mPtr,mLen,pPtr,pLen) -> id` | starts handler goroutine (chan cap 16 = backpressure) |
| `wasmrpc_stream_recv(id) -> u64` | blocking pull of the next frame |
| `wasmrpc_stream_cancel(id)` | cancels the handler context |

Frame layout `[status u8][payload]`: `0` message, `1` end, `2` error
(payload = `code\nmethod\nmessage`). `examples/e2e/wasip1host` is a
complete wazero-embedded host exercising all of it.

## TinyGo

The runtime avoids protobuf reflection whenever messages carry
vtprotobuf's `MarshalVT`/`UnmarshalVT` (generated by default here) —
required because `reflect.NewAt` inside protobuf-go crashes TinyGo, and
a free speed win for big Go.

| | big Go | TinyGo 0.38 |
|---|---|---|
| browser module size | ~6.4 MB | **~1.2 MB** |
| wasip1 module size | ~6.4 MB | **~1.1 MB** |
| unary + streams + cancel | ✅ | ✅ |
| panic → `internal` error | ✅ | ❌ aborts module |

TinyGo does not support `recover()` on wasm (any scheduler — verified
empirically), so services targeting TinyGo must return `server.Errorf`
instead of panicking. Also avoid `select`+`time.After` pacing in
handlers; use `time.Sleep` (portable to the asyncify scheduler).

## Usage

Server (any target):

```go
r := server.NewRouter()
echov1.RegisterEchoServiceServer(r, echo.New())   // unary + streams
r.Mount("wasmRPC")                                // browser
// or: server.Attach(r) from init()               // wasip1 reactor
```

Streaming handler:

```go
func (s *Service) Watch(ctx context.Context, req *echov1.WatchRequest, stream *server.ServerStream[*echov1.WatchResponse]) error {
	for i := uint32(1); i <= req.GetCount(); i++ {
		if err := stream.Send(&echov1.WatchResponse{Seq: i}); err != nil {
			return err // cancelled
		}
	}
	return nil
}
```

Clients:

```ts
const stream = client.watch({ message: "tick", count: 10 });
for await (const t of stream) { if (t.seq === 3) stream.cancel(); }
```

```dart
await for (final t in client.watch(WatchRequest(count: 10))) { ... }
```

```kotlin
client.watch(req).collect { t -> ... }          // Flow<WatchResponse>
```

```swift
for try await t in client.watch(req) { ... }    // AsyncThrowingStream
```

```go
err := c.Watch(ctx, req, func(t *echov1.WatchResponse) error { return nil })
```

Errors reject uniformly as `{code, method, message}`: `invalid_argument`
(incl. invoke/listen kind mismatch), `unimplemented`, `internal`,
`unknown`.

## Memory-boundary contract

One `CopyBytesToGo` per request into a pooled buffer; responses/frames
via pooled `MarshalAppend` (or reflection-free `MarshalVT`), one
`CopyBytesToJS`, then recycled. Frame bytes are valid only during the
send/onMessage call. No element-wise `js.Value` traffic; handlers run on
goroutines, the JS event loop never blocks.
